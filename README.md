## 它需要你的 Session，这件事得看明白

WildAI 全程不要你的账号密码，但要你的 Session（登录凭据）。它的用途是自动登录对应账号，去处理订阅和后续几个月的续订。

这里有个需要你自己权衡的取舍：密码没给，账号的主控制权还在你手里，这比直接卖共享号安全；但 Session 在技术上是能代表你操作账号的凭据，平台在订单处理期间持有它。你能接受这个授权范围，再往下走；不能接受，就别用任何代订阅服务，老老实实解决官方支付。
